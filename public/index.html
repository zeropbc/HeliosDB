Data access

There is no live API in production — HeliosDB ships as static JSON on GitHub Pages. Consume it directly:

GET data/index.json              # [{id, name, aliases, classification, parent_id}]
GET data/bodies/<id>.json       # full canonical record

Local dev server (./server.sh, dev only) mirrors this shape:

GET /api/v1/bodies?q=titan&class=regular-moon&parent=saturn&sort=radius_km&limit=50&offset=0
GET /api/v1/bodies/<id>
GET /api/v1/systems/<parent_id>
GET /api/v1/export/helios
GET /api/v1/stats

IDs are stable slugs (?focus=<id> deep-links keep working); renamed bodies keep old designations in designations.
